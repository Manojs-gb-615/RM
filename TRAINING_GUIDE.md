## Prerequisites

Before training, ensure:

- [ ] Virtual environment is activated (or use full Python path)
- [ ] All dependencies installed (`pip install -r requirements.txt`)
- [ ] MediaPipe pose `.npy` files extracted for train/val/test splits
- [ ] Pose manifest files generated by `prepare_manifests.py`
- [ ] At least 4 GB GPU VRAM available (RTX 2050 minimum)
- [ ] CUDA-enabled PyTorch installed (`torch.cuda.is_available()` returns `True`)

**Set the Python variable (PowerShell):**
```powershell
$PYTHON = "c:\Users\manoj\Downloads\context_aware_howsign_project\.venv\Scripts\python.exe"
```

## Running Each Experiment

> **Replace `<data_dir>`** with the path to your directory containing `poses/` and `annotations/` subdirectories.

### E1: Text-Only Baseline

```powershell
& $PYTHON train.py `
    --experiment E1 `
    --data_dir <data_dir> `
    --context_window 0 `
    --batch_size 16 `
    --epochs 50 `
    --lr 1e-4 `
    --output_dir checkpoints/E1
```

### E2: Context-Aware (1 Prior Sentence)

```powershell
& $PYTHON train.py `
    --experiment E2 `
    --data_dir <data_dir> `
    --context_window 1 `
    --fusion cross_attention `
    --batch_size 16 `
    --epochs 50 `
    --lr 1e-4 `
    --output_dir checkpoints/E2
```

### E3: Longer Context (2–3 Prior Sentences)

```powershell
& $PYTHON train.py `
    --experiment E3 `
    --data_dir <data_dir> `
    --context_window 3 `
    --fusion cross_attention `
    --batch_size 8 `
    --epochs 50 `
    --lr 1e-4 `
    --output_dir checkpoints/E3
```

> Note: Batch size reduced to 8 for E3 due to larger context inputs fitting in 4GB VRAM.

### E4: Text-History Control

```powershell
& $PYTHON train.py `
    --experiment E4 `
    --data_dir <data_dir> `
    --context_window 1 `
    --context_type text `
    --fusion cross_attention `
    --batch_size 16 `
    --epochs 50 `
    --lr 1e-4 `
    --output_dir checkpoints/E4
```

### E5: Zero-Context Probe (No Retraining)

E5 evaluates the **trained E2 checkpoint** with context zeroed out. No separate training run:

```powershell
& $PYTHON evaluate.py `
    --experiment E5 `
    --checkpoint checkpoints/E2/best_model.pt `
    --data_dir <data_dir> `
    --zero_context `
    --output_dir results/E5
```

### E6: Shuffled-Context Probe (No Retraining)

E6 evaluates the **trained E2 checkpoint** with context drawn from a different video:

```powershell
& $PYTHON evaluate.py `
    --experiment E6 `
    --checkpoint checkpoints/E2/best_model.pt `
    --data_dir <data_dir> `
    --shuffle_context `
    --output_dir results/E6
```

### E7: Fusion Ablation (Concat instead of CrossAttention)

## Checkpoint Format

The `Trainer` class (in `src/training/trainer.py`) saves checkpoints in the following format:

```
checkpoints/E2/
├── best_model.pt          ← best validation loss checkpoint
├── checkpoint_epoch_10.pt ← periodic checkpoint every N epochs
├── checkpoint_epoch_20.pt
├── ...
└── training_log.jsonl     ← per-epoch metrics log
```

**Checkpoint contents** (`.pt` file — PyTorch `state_dict` dictionary):
```python
{
    "epoch": int,
    "model_state_dict": OrderedDict,          # model weights
    "optimizer_state_dict": OrderedDict,       # optimizer state
    "scheduler_state_dict": OrderedDict,       # LR scheduler state
    "best_val_loss": float,
    "config": dict,                            # experiment config
    "kl_weight": float,                        # current KL annealing weight
}
```

**Loading a checkpoint:**
```python
checkpoint = torch.load("checkpoints/E2/best_model.pt", map_location="cuda")
model.load_state_dict(checkpoint["model_state_dict"])
optimizer.load_state_dict(checkpoint["optimizer_state_dict"])
start_epoch = checkpoint["epoch"] + 1
```

## Resuming Training

If training is interrupted, resume from the latest checkpoint:

```powershell
& $PYTHON train.py `
    --experiment E2 `
    --data_dir <data_dir> `
    --context_window 1 `
    --resume checkpoints/E2/checkpoint_epoch_20.pt `
    --epochs 50 `
    --output_dir checkpoints/E2
```

The `--resume` flag loads the checkpoint and continues from the saved epoch, restoring optimizer state and KL annealing position.

## Hyperparameter Notes

| Hyperparameter | Default | Notes |
|---------------|---------|-------|
| `learning_rate` | 1e-4 | AdamW; DistilBERT layers may use a lower LR (1e-5) |
| `batch_size` | 16 | Reduce to 8 for E3 or if OOM errors occur |
| `max_frames` | 300 | Truncate/pad pose sequences to this length |
| `max_text_len` | 128 | Tokenizer max length |
| `d_model` | 256 | Hidden dimension throughout |
| `latent_dim` | 128 | CVAE latent size |
| `decoder_layers` | 4 | Transformer decoder depth |
| `decoder_heads` | 8 | Multi-head attention heads |
| `kl_warmup_steps` | 1000 | Steps before KL annealing begins |
| `kl_anneal_steps` | 5000 | Steps to ramp KL weight to β_max |
| `beta_max` | 1.0 | Maximum KL weight |
| `weight_decay` | 1e-2 | AdamW weight decay |
| `gradient_clip` | 1.0 | Max gradient norm |
| `patience` | 10 | Early stopping patience (epochs) |

**RTX 2050 4GB guidance:**
- If CUDA OOM: reduce `batch_size` or `max_frames`
- Enable gradient checkpointing if VRAM is insufficient: `--gradient_checkpointing`
- Use `--fp16` for mixed precision training (may reduce VRAM by ~30%)

## Early Stopping

The trainer implements early stopping on validation reconstruction loss:

- If validation loss does not improve for `--patience` epochs (default: 10), training stops.
- The best checkpoint (by validation loss) is always saved as `best_model.pt`.
- Early stopping is **recommended** to prevent overfitting on the small How2Sign dataset.

**Disabling early stopping:**
```powershell
& $PYTHON train.py --experiment E2 ... --patience 999
```
