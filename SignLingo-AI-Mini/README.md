# SignLingo AI Mini — README

**Lightweight Context-Aware ASL Pose Retrieval from Short Educational Videos.**

> ⚠️ **Research prototype.** This system retrieves nearest-match ASL poses from a small dataset.
> It does not generate novel ASL, and retrieved poses have not been evaluated by qualified ASL signers.
> Always display the "No reliable ASL pose available" fallback for unmatched sentences.

---

## What it does

1. Upload a short educational MP4 (30–60 seconds)
2. Upload its English transcript (.srt or .vtt)
3. The system identifies each sentence and retrieves the closest ASL pose clip from the dataset
4. Watch the video and ASL skeleton animation side by side
5. Compare **text-only** vs **context-aware** retrieval (the latter uses the previous sentence and signing context)

## Quick Start

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
cd ..
```

### 3. Get How2Sign data (required for real ASL poses)

1. Register at https://how2sign.github.io/
2. Download **2D Mediapipe pose files** (body + hand, .npy format)
3. Place `.npy` files in `data/poses/` named by `sentence_id` (e.g. `--7E8rIUe34_19-6-rgb_front_0.npy`)
4. Download `how2sign_realigned_train.csv` and use it to populate `data/metadata.csv`

The `metadata.csv` format:
```
sample_id,sentence,video_id,narrative_id,start_time,end_time,prev_sample_id
```

Generate a template:
```bash
python -c "from ml.dataset import create_metadata_template; create_metadata_template()"
```

### 4. Build retrieval index

**Option A — Google Colab (recommended for training):**
- Open `notebooks/train_signlingo.ipynb` in Colab
- Run all cells
- Download `models/retrieval_index.pkl`
- Place it in `SignLingo-AI-Mini/models/`

**Option B — local (requires pose data):**
```bash
python ml/train.py --data-dir data --eval
```

**Option C — synthetic test only (no real ASL):**
```bash
python ml/train.py --synthetic --eval
```

### 5. Start the backend

```bash
uvicorn backend.main:app --reload --port 8000
```

### 6. Start the frontend

```bash
cd frontend
npm run dev
```

Open http://localhost:5173

## API endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/api/health` | GET | Health check |
| `/api/status` | GET | Model ready state + counts |
| `/api/dataset/samples` | GET | All dataset samples |
| `/api/dataset/samples/{id}/pose` | GET | Pose array for a sample |
| `/api/retrieve` | POST | Retrieve best pose for a sentence |
| `/api/compare` | POST | Run text-only vs context-aware |
| `/api/transcript/parse` | POST | Parse .srt or .vtt file |
| `/api/transcript/retrieve_all` | POST | Retrieve poses for every segment |

## Limitations

- Retrieval only — no novel ASL generation
- Small dataset (20–50 clips for prototype)
- Poses not certified by qualified ASL signers
- Context awareness depends on dataset diversity
- Not suitable for accessibility tools without human evaluation
